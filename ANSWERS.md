# Answers

Each image was viewed on its own (upscaled 4x so the details were legible).

A note on how I read these: every image is a pixel-art endless-runner scene
(Subway Surfers style) looking forward down a set of train tracks, with one
yellow obstacle straddling the lane. The obstacle is a portal/gantry frame:
two vertical legs planted either side of the lane, a horizontal top beam
between them, and a yellow-and-black diagonal hazard-striped board hanging
from that beam. The striped board stops well short of the ground — under it
the track sleepers and rails run through unbroken — so the gap between the
legs is open. That open gap is why the answer to question 2 comes out the
same way each time; I checked it image by image rather than assuming it.

The lane beneath is a glowing cyan track section.
2. **Over / under / around:** **Under.**

   *Why:* the striped board hangs from the top beam with a clear open span beneath it — the sleepers and the cyan lane run straight through the gap between the legs — so the only way past is to duck through that gap.
